# POA PRA TI

Site educacional desenvolvido com HTML, CSS e JavaScript.

## Como abrir
1. Extraia a pasta `POA-PRA-TI`.
2. Abra a pasta no VS Code.
3. Abra o arquivo `index.html` no navegador (ou use a extensão Live Server).
4. Os arquivos CSS, JavaScript e imagens já estão organizados nas pastas.

## Páginas
- `index.html`: página inicial com busca e filtro.
- `evento1.html`: Porto Alegre Encantada.
- `evento2.html`: Réveillon Porto Alegre 2027.
